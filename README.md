# Calculadora Java ☕

🇧🇷 Calculadora desktop desenvolvida em Java utilizando Swing/JFrame.

🇺🇸 Desktop calculator developed in Java using Swing/JFrame.

---

## ✨ Funcionalidades | Features

### 🇧🇷

* Soma
* Subtração
* Multiplicação
* Divisão
* Potenciação
* Raiz quadrada
* Porcentagem
* Inverso (1/x)

### 🇺🇸

* Addition
* Subtraction
* Multiplication
* Division
* Exponentiation
* Square root
* Percentage
* Reciprocal (1/x)

---

## ⌨️ Recursos | Resources

### 🇧🇷

* Suporte ao teclado
* Números decimais
* Números negativos
* Limpar entrada
* Limpar tudo
* Histórico de operações

### 🇺🇸

* Keyboard support
* Decimal numbers
* Negative numbers
* Clear entry
* Clear all
* Operation history

---

## 🛠 Tecnologias utilizadas | Technologies Used

* Swing
* JFrame
* NetBeans

## 📚 Objetivo do projeto | Project Goal

### 🇧🇷

Projeto desenvolvido para praticar:

* Interfaces gráficas com Swing
* Programação orientada a eventos
* Manipulação de teclado
* Lógica de programação
* Tratamento de erros

### 🇺🇸

Project developed to practice:

* Swing graphical interfaces
* Event-driven programming
* Keyboard event handling
* Programming logic
* Error handling

---

## 🚀 Como executar | How to Run

### 🇧🇷

1. Clone o repositório
2. Abra o projeto no NetBeans
3. Execute a classe principal (`principal.java`)

### 🇺🇸

1. Clone the repository
2. Open the project in NetBeans
3. Run the main class (`principal.java`)

```bash
git clone https://github.com/AlineGuilhoto/java-swing-calculator.git
```
